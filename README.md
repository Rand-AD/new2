# Yalla Rewards App

Yalla Rewards is a mobile application for mall customers.

The app allows users to collect points, redeem rewards, view offers, check mall announcements, and browse shops in one place.

## About

This project was developed as a graduation project for the Software Engineering Department at Jordan University of Science and Technology.

The main idea of the app is to replace traditional paper coupons and scattered offers with a simple digital loyalty system.

## Main Features

- Login and registration
- OTP verification
- View user points
- Earn and redeem rewards
- View offers
- View announcements
- Browse shops
- View reward history
- User profile
- API integration
